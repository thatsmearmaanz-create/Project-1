What was the idea?

The idea behind this project was to create a place where students could look through different workshops and find the information they need. I wanted the website to be simple so users would not have to spend too much time looking for things.

How I approached it

I started by dividing the page into different sections. The main information is shown in a larger area, while other workshops are displayed in smaller cards. I tried to keep the layout organized so it would be easy to follow.

What I used

  • HTML to create the content of the website.
  • CSS Grid to organize the main sections.
  • Flexbox to arrange smaller items and cards.
  • Media queries to change the layout for mobile screens.

What I learned

This project gave me more practice with CSS Grid and Flexbox. I learned that Grid is useful for organizing larger sections of a page, while Flexbox works well for arranging items inside those sections. I would like to add more features to the website if I had more time, such as working search and category filters.
